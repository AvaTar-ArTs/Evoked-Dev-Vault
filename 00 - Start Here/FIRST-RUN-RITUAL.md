# First-Run Ritual

## Prepare

- [ ] Open this repository as a separate Obsidian vault.
- [ ] Confirm the vault is not your production vault.
- [ ] Install only the plugins being tested.
- [ ] Confirm no API keys are stored in notes.

## Seed the laboratory

- [ ] Add one image, one audio file, one video file, one code file, one dataset, one PDF, and one Markdown note to `02 - Assets/`.
- [ ] Create one project in `01 - Projects/`.
- [ ] Add one source card to `03 - Research/`.
- [ ] Add one agent specification to `04 - Agents/`.
- [ ] Add one storyworld entity to `05 - Worlds/`.

## Test the loop

- [ ] Run Ingest.
- [ ] Run Assetarium inventory.
- [ ] Capture a Mnemosyne memory capsule.
- [ ] Design an Alchemy recipe.
- [ ] Review the output manually.
- [ ] Create a Dispatch pack.
- [ ] Export only after checking source fidelity.
