# Evoked Dev Vault

This is the laboratory for Evoked: a creative operating system for assets, memory, research, agents, workflows, storyworlds, and publishing.

## The operating loop

```text
Ingest → Understand → Remember → Automate → Review → Dispatch → Learn
```

## First three actions

1. Read [[FIRST-RUN-RITUAL]].
2. Add a small sample set to `02 - Assets/`.
3. Create a project note from `Templates/Project.md`.

## Rules of the vault

- Markdown and ordinary files remain the source of truth.
- AI suggestions are drafts until explicitly approved.
- Every external call has a visible purpose.
- Every workflow has a human checkpoint.
- The `99 - Scratch/` folder is disposable.
