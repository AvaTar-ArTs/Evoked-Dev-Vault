# Evoked Dev Vault

A safe Obsidian development vault for building, testing, documenting, and publishing the Evoked creative-automation plugin ecosystem.

This vault is intentionally separate from a personal production vault. It gives each plugin a place to be tested against realistic assets, research, agents, storyworlds, workflows, and publishing outputs.

## Quick start

1. Clone or download this repository.
2. In Obsidian, choose **Open folder as vault** and select this folder.
3. Install the Evoked plugins manually or from their Community releases when available.
4. Start with `00 - Start Here/EVOKED-START-HERE.md`.
5. Run the first-run ritual in `00 - Start Here/FIRST-RUN-RITUAL.md`.

## Vault zones

```text
00 - Start Here/     orientation and setup
01 - Projects/       active products, experiments, and builds
02 - Assets/         images, audio, video, code, data, documents
03 - Research/       sources, claims, evidence, and market notes
04 - Agents/         agent specs, skills, tools, MCP, and run logs
05 - Worlds/         characters, motifs, places, timelines, continuity
06 - Workflows/      Alchemy recipes and automation designs
07 - Memory/         decisions, lessons, preferences, style DNA
08 - Dispatch/       content packs and distribution drafts
09 - Exports/        HTML reliquaries, releases, and delivery packages
99 - Scratch/        disposable experiments
```

## Recommended plugin order

Evoked Ingest → Assetarium → Mnemosyne → Alchemy → Agent Atelier → Research Loom → Storyworlds → Dispatch.

Resonance, Oracle, Constellations, Forge, Reliquary, and Rituals are optional modules that can be added after the core workflow is stable.

## Privacy

The vault contains no telemetry configuration and no API keys. Keep secrets in environment variables or the provider's secure settings, never in Markdown.
